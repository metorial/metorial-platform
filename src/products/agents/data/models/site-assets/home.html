Metorial Model Catalog

Every model, family, lab and vendor offering we track, regenerated hourly from public sources. Static JSON, open to any origin.

  • catalog.json.gz: the whole catalog, gzipped
  • models.json: models, releases and pointers
  • families.json
  • organizations.json
  • vendors.json: vendors and endpoints
  • offerings.json: what each vendor sells, with pricing
  • names.json: every vendor model name and what it resolves to
  • agents.json: coding agents, their makers and the vendors they use

One file per entity: /models/<id>.json, /families/<id>.json, /vendors/<id>.json, /agents/<id>.json and /organizations/<id>.json. Ids can contain a slash, for example /models/anthropic/claude-opus-4.json.

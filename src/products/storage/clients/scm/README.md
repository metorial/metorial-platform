# `@mtsrc/scm-client-internal`

TypeScript RPC client for the Storage product’s [SCM service](../../services/scm/services/api).

```ts
import { createOriginClient } from '@mtsrc/scm-client-internal';

let origin = createOriginClient({
  endpoint: 'https://example.com/metorial-origin'
});
```

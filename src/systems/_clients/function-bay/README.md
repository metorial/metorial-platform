# Metorial Function Bay Client

A client library for interacting with the Metorial Function Bay platform using TypeScript.

## Usage

```ts
import { createFunctionBayClient } from '@metorial-platform-systems/function-bay-client';

let functionBay = createFunctionBayClient({
  endpoint: '...'
});
```

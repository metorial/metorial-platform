# Metorial Shuttle Client

A client library for interacting with the Metorial Shuttle platform using TypeScript.

## Usage 

```ts
import { createShuttleClient } from '@lowerdeck/Shuttle-client';

let Shuttle = createShuttleClient({
  endpoint: '...'
});
```
